# Azamat_new_pictures

## Быстрый запуск перед демонстрацией

1. Откройте `Azamat.html` в браузере.
2. Войдите как гость — для чата не нужен локальный сервер авторизации.
3. Введите действующий ключ Google Gemini в поле `API Key` и нажмите `OK`.
4. Отправьте короткое тестовое сообщение и проверьте, что появился ответ.

Чат сохраняет историю и ключ Gemini в `localStorage` этого браузера. Для показа без интернета или без действующего ключа ответы Gemini недоступны.

## Бесплатная озвучка Edge TTS

Для русской и казахской озвучки без ElevenLabs установите зависимость и запустите локальный сервис:

```powershell
py -m pip install -r requirements-tts.txt
py tts_server.py
```

По умолчанию кнопка динамика использует ElevenLabs. Если ElevenLabs недоступен, приложение пробует локальный Edge TTS как запасной вариант. Для более естественной озвучки через Azure Speech перед запуском сервера задайте ключ и регион ресурса Azure:

```powershell
$env:AZURE_SPEECH_KEY = "ваш ключ Azure Speech"
$env:AZURE_SPEECH_REGION = "ваш регион, например eastus"
py tts_server.py
```

Ключ остаётся только в переменной текущего окна PowerShell и не попадает в HTML или Git. Когда эти две переменные заданы, кнопка динамика использует Azure Speech:

- казахский: `kk-KZ-DauletNeural`;
- русский: `ru-RU-DmitryNeural`.

Если локальный сервис не запущен, приложение автоматически попробует ElevenLabs при наличии сохранённого ключа. API-ключи не нужно добавлять в исходный код.

Перед публичной демонстрацией не публикуйте API-ключи в репозитории и проверьте лимит ключа Google Gemini в Google AI Studio.
