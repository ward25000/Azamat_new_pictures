# Azamat_new_pictures

## Презентация

Для показа возможностей Азамата откройте [presentation.html](./presentation.html). Английская версия доступна в [presentation-en.html](./presentation-en.html). В презентациях есть навигация стрелками и кнопками, визуальные макеты интерфейса, голосового режима и анализа изображений.

## Быстрый запуск перед демонстрацией

1. Откройте `Azamat.html` в браузере.
2. Войдите как гость — для чата не нужен локальный сервер авторизации.
3. Введите действующий ключ Google Gemini в поле `API Key` и нажмите `OK`.
4. Отправьте короткое тестовое сообщение и проверьте, что появился ответ.

Чат сохраняет историю и ключ Gemini в `localStorage` этого браузера. Для показа без интернета или без действующего ключа ответы Gemini недоступны.

## Озвучка ElevenLabs

Кнопка динамика использует ElevenLabs напрямую. Сначала сохраните ключ ElevenLabs в интерфейсе рядом с ключом Gemini. API-ключи не нужно добавлять в исходный код.

Перед публичной демонстрацией не публикуйте API-ключи в репозитории и проверьте лимит ключа Google Gemini в Google AI Studio.
